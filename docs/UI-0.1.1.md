# 0.1.1 界面调整

本次沿用已确认的 Windows 原生、轻量工具方向，没有引入网页界面或新的第三方依赖。

## 改动

- 启用 Windows Common Controls v6 系统主题，替换旧式控件外观。清单同时明确普通用户权限。
- 使用系统字体，统一标题、分组、正文和辅助说明的字号与间距。
- 顶部状态区突出即时回放状态和实际检测方式，加入可直接操作的暂停/恢复按钮。
- 按“检测设置、自动恢复、常规选项”分组；标签和输入对齐，快捷键集中在一行。
- 开启、关闭、未知及暂停使用有文字说明的状态颜色，不只依赖颜色表达。
- 独立的可滚动诊断区域，保留完整错误消息，连接测试结果改为容易理解的说明。
- 修复检测与重试间隔下拉框的辅助功能标签顺序。
- 设置仍然按需创建。字体和画刷由窗口持有，退出时释放；没有持续动画或绘制定时器。

`build.rs` 将 `app.manifest` 嵌入 EXE，源码构建时需要保留这两个文件。颜色与绘制代码集中在 `src/ui_style.rs`。

## 验证

- 25 项自动化测试通过；严格 Clippy 检查通过；发布编译成功。
- 使用独立只读预览，实际检查了窗口显示、状态区域、分组、文字对齐和辅助功能信息。
- 实际点击暂停按钮，确认状态、按钮文字和配色同步改变；点击检测测试按钮，确认诊断区域显示进度。
- 预览过程中发现并修正了原生绘制回调重入时产生的状态区灰底；没有触发录制或修改自启。
- 保留用户已有的旧版后台监控，测试只结束本次预览进程。
- EXE 为 486,400 字节（475 KiB），相对 0.1.0 增加 7 KiB。

## 升级

先从托盘退出旧版，再运行新版 EXE。设置文件路径未改变，原有配置继续使用。若启用了自启并更换 EXE 路径，需要在新版中关闭再开启自启，以更新路径。

开发检查可运行 `replay-guardian.exe --preview`：独立只读窗口可以与正常监控并存，预览不自动恢复、不修改自启，也不保存设置。
